```bash

pip install -r requirements.txt

# 2) 采集（默认 2021-2026，请求间隔 1.2s，失败重试 3 次）

# 常用参数
python spider_ranking.py --years 2024-2026    # 只采部分年份
python spider_ranking.py --from-cache         # 不联网，用本地 JSON 缓存重建 CSV

```

## 3. 数据来源与采集策略

软科榜单页（`/rankings/bcur/2025`）为 Nuxt 服务端渲染页，表格数据不在 HTML 中，
但页面同源公开接口直接返回完整 JSON，因此**不解析 HTML，直接调用接口**：

```
GET https://www.shanghairanking.cn/api/pub/v1/bcur?bcur_type=11&year=2026
```

- `bcur_type=11` = 中国大学排名**主榜**（综合/理工/师范/农业/林业，每年约 580-600 所）
- 每次运行只需 6 个请求，请求间随机间隔 ≥1.2s，带浏览器 UA 与 Referer，符合文档 §9「加延时防封」
- 每年原始响应落盘 `data/raw_json/`，接口挂掉时可用 `--from-cache` 重建，保证可复现
- **不做清洗**：排名保留 `500+` 原样、分数保留接口原值，去重/类型转换留给阶段 2 `load_data.py`

## 4. 字段字典（rankings_raw.csv）

| 列名 | 类型 | 来源 | 说明 |
|---|---|---|---|
| year | int | 循环参数 | 2021-2026 |
| rank | text | `ranking` | 当年名次；500 名之后软科写作 `500+`，阶段 2 转整数 |
| univ_name | text | `univNameCn` | 学校中文名 |
| univ_name_en | text | `univNameEn` | 学校英文名 |
| univ_slug | text | `univUp` | 软科学校唯一标识，用于跨年份关联（阶段 2 建 university 表主键映射） |
| province | text | `province` | 省级行政区（31 个有数据，港澳台无软科排名） |
| univ_type | text | `univCategory` | 综合/理工/师范/农业/林业 |
| level | text | `univTags` | 985/211/双一流，多标签用 `/` 连接；普通院校为空 |
| is_985 / is_211 / is_double | 0/1 | `univTags` | 层次布尔标记，供阶段 2 直接入库 |
| score_total | float | `score` | 总分；500+ 学校软科不发布，为空 |
| score_research | float | `indData[科学研究]` | 科研得分；仅前 100 名有值 |
| score_talent | float | `indData[人才培养]` | 人才培养得分；仅前 100 名有值 |
| score_social | float | `indData[服务社会]` | 社会服务得分；仅前 100 名有值 |
| stars | int 1-5 | 派生 | 软科主榜不发布星级，按名次分段映射（见下） |

**星级映射规则（派生字段，非官方数据）**：1-10 名 → 5 星；11-50 → 4 星；51-200 → 3 星；201-500 → 2 星；500+ → 1 星。

指标编号（`indData` 的 key）每年不同（2021 是 159-168，2026 是 788-797），脚本从响应的 `inds` 元数据动态取映射，不写死。

## 6. 已知限制与阶段 2 衔接

1. **城市字段已取消**（用户阶段 2 决定）：软科接口与学校详情页（`/institution/<slug>`）都只给省份，
   阳光高考院校库对本机返回 HTTP 412（反爬）。因此不再保留 `city` 列，`university` 表也不建该字段。
2. **分项得分只有前 100 名**：F08「科研 vs 人才培养散点图」只能用每年前 100 名，
   每年 100 个点已足够做散点与框选联动；阶段 6 会按此口径实现。
3. **500+ 学校无总分**：阶段 2 入库时 `score_total` 置 NULL，趋势图与地图按学校数量/层次统计，
   不受影响；排名趋势图对这类学校只画「500+」档位线。
4. **港澳台无数据**：ECharts 中国地图有 34 个省级行政区，港澳台将显示为「无数据」，
   前端用灰色底 + tooltip「暂无软科排名数据」处理。
5. **排名并列**：软科存在并列名次（如两个第 5），CSV 保留原值不去重，
   阶段 2 以 `(univ_id, year)` 唯一约束保证一校一年一条。
