# 快速启动与常见问题

## 1. 一键启动（推荐）

双击项目根目录的 **start.bat**：

- 自动切到项目目录、启动 Flask、并在浏览器打开 http://127.0.0.1:5000/
- 数据库账号密码已写入 `config.py`，**不需要再设置环境变量**
- 启动时会先检查数据库连接，控制台会打印：

```
========================================================
  全国大学数据分析大屏 · 后端服务
  访问地址 : http://127.0.0.1:5000/
  数据库   : root@127.0.0.1:3306/university
  连接状态 : [OK] 已连接（university 表 600 行）
========================================================
```

命令行方式等价于：

```powershell
cd C:\Users\warn\Desktop\ssh
python app.py            # 启动
python app.py --open     # 启动并自动打开浏览器
```

> 首次在新机器运行，先装依赖：`pip install -r requirements.txt`。

## 2. 数据库配置在哪

`config.py`：

```python
DB_CONFIG = {
    "host": "127.0.0.1",
    "port": 3306,
    "user": "root",
    "password": "123456",   # ← 改这里
    "database": "university",
}
```

- 环境变量 `MYSQL_PASSWORD` 等仍可临时覆盖（优先级高于 config.py）
- 命令行也可覆盖：`python app.py --db-password 其他密码`

> ⚠️ 按你的要求密码已直接存入项目。仅用于本机实训；
> 若以后要推到 GitHub / 公网，请先把密码换成环境变量并轮换。

## 3. 出现 500 / Failed to load resource 怎么排查

浏览器里 `/api/*` 返回 500，几乎都是 **后端连不上 MySQL**。按顺序检查：

| 步骤 | 操作 | 正常表现 |
|---|---|---|
| 1 | `Get-Service MySQL` | Status = Running |
| 2 | `python app.py` 看启动输出 | 显示 `连接状态 : [OK]` |
| 3 | 打开 `http://127.0.0.1:5000/api/health` | `{"code":0,...,"status":"ok"}` |
| 4 | 核对 `config.py` 的账号密码 | 与 MySQL 实际账号一致 |
| 5 | 检查是否残留旧进程 | `Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Where-Object { $_.CommandLine -match "app.py" }` |

**常见原因与处理：**

1. **MySQL 服务没启动** → `Start-Service MySQL`
2. **密码错误 / 不是本机这套库** → 改 `config.py` 后重启 `python app.py`
3. **端口被旧的 app.py 进程占用**：旧进程可能还跑着旧代码/旧密码，
   新进程起不来或你以为重启了其实没有。处理：
   ```powershell
   Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
     Where-Object { $_.CommandLine -match "app.py" } |
     ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
   ```
   然后再 `python app.py`。
   现在程序会检测端口占用并提示「大屏可能已经在运行」。
4. **表不存在 / 数据没导入** → `python load_data.py` 重新入库。

**现在的错误提示更友好**：数据库异常会返回可读中文（含 MySQL 原始错误），
页面顶部出现红色横幅 + 「重试」按钮，页脚状态灯变红；不再只有一行 500。
效果见 `docs/screenshots/error_state.png`。

## 4. 其它

| 需求 | 做法 |
|---|---|
| 换端口 | `python app.py --port 5001`（访问 http://127.0.0.1:5001/） |
| 只看某个年份/学校 | `http://127.0.0.1:5000/?year=2024&school=浙江大学` |
| 只调接口 | `http://127.0.0.1:5000/api/map_data?year=2026` |
| 接口全面自检 | `python check_api.py` |
| 大屏自动化自检 | `python check_dashboard.py`（需 `pip install -r requirements-dev.txt`，复用本机 Chrome/Edge） |
| 重新导入数据 | `python load_data.py`（会清空 university/ranking 后重导） |
